## 🌟 Overview

**AI Text Cleaner & Image Sanitizer** is a high-performance web utility built to solve real-world problems faced by writers, developers, e-commerce sellers, and digital creators when working with AI-generated text and images (ChatGPT, Claude, Gemini, Midjourney, DALL-E 3, Stable Diffusion, and Flux.1).

100% of processing runs **locally inside the user's browser memory** using Web APIs, ArrayBuffer parsing, and HTML5 Canvas. Zero data or images are ever uploaded to cloud servers.

## 🔍 Real User Issues Addressed (Researched from Reddit & Creator Forums)

### 1. AI Text Formatting & Invisible Watermarks
* **Invisible Control Characters (`U+200B`, `U+00A0`, Soft Hyphens)**: Large Language Models (LLMs) and chat UIs insert invisible zero-width spaces and non-breaking spaces that break code compilers, regex, JSON payloads, and word counts.
* **Markdown Formatting Leakage**: Copying from ChatGPT includes asterisks (`**bold**`), headers (`###`), backticks (```), and lists that ruin CMS formatting in WordPress, Medium, or Google Docs.
* **Robotic AI Cliché Vocabulary**: Overused AI terms (*"delve"*, *"tapestry"*, *"realm"*, *"testament"*, *"pivotal"*, *"foster"*) make writing sound artificial and trigger basic AI detection heuristics.
* **Smart Quotes & Curly Characters**: ChatGPT outputs curly quotes (`“ ” ‘ ’`) and em-dashes (`—`) that crash code, SQL queries, and developer builds.

### 2. AI Image Metadata & Tracking Headers
* **Prompt Engineering Leaks**: PNG/JPEG files generated by Midjourney, DALL-E 3, or Stable Diffusion embed full prompt strings, seed numbers, and sampler settings inside file chunks (`tEXt`/`iTXt`). Competitors can download your image and steal your prompt techniques.
* **C2PA Content Credentials Watermarks**: OpenAI (ChatGPT), Google (Gemini/Imagen), and Adobe attach digital C2PA provenance headers (`c2pa.action`, `trainedAlgorithmicMedia`) directly into image files.
* **E-Commerce & Stock Site Rejections**: Platforms (Etsy, Amazon, stock photo sites) scan file headers for C2PA or generator tags (`DALL-E 3`, `Midjourney`) and reject listings.
* **Visual AI Detector Fingerprints**: Neural network detectors (Hive Moderation, Illuminarty) analyze high-frequency pixel textures and diffusion grid alignments to flag images as AI-generated even if EXIF tags are deleted.

## 🚀 Current Browser-Based Features

### 📝 AI Text Sanitizer
* **Invisible Unicode Stripper**: Finds and removes zero-width spaces (`U+200B`), non-breaking spaces (`U+00A0`), soft hyphens (`U+00AD`), and control characters.
* **AI Buzzword Filter**: Normalizes cliché AI vocabulary (*delve, tapestry, realm, testament, pivotal, foster, digital landscape*).
* **Markdown to Plain Text**: Strips bold asterisks, backticks, header hashes, and links while preserving clean paragraph structure.
* **Smart Quotes to Straight Quotes**: Converts curly quotes (`“ ” ‘ ’`) to straight ASCII (`" '`) and normalizes em-dashes (`—`) to standard hyphens (`-`).
* **Platform Presets**: One-click cleaning presets for **ChatGPT**, **Claude**, **Google Gemini**, **Copilot**, and **Code/JSON Safe**.

### 🖼️ AI Image Sanitizer & Metadata Stripper (`/remove-ai-image-metadata`)
* **Header Inspection Engine**: ArrayBuffer binary parser reads raw PNG/JPEG chunks in browser memory and displays detected metadata before cleaning:
  * Generator / Model Signature
  * C2PA Content Credentials Status
  * EXIF Camera Tags
  * Embedded Prompt & Parameter String Preview
* **Canvas Pixel Sanitization**: Draws visual pixels onto an off-screen HTML5 `<canvas>` and exports a clean JPEG/PNG file, wiping 100% of hidden headers, prompts, and C2PA manifests.
* **20+ Generator Detection**:
  * ChatGPT / DALL-E 3 (OpenAI C2PA)
  * Google Gemini / Imagen 3
  * Midjourney (v5/v6)
  * Stable Diffusion (Automatic1111 / ComfyUI / SDXL)
  * Flux.1 AI (Black Forest Labs / Fal.ai)
  * Adobe Firefly & Photoshop AI
  * Meta AI Imagine, Ideogram, Leonardo.Ai, Bing Image Creator, Canva Magic Media, NightCafe, Krea.ai, Recraft AI
* **Enhanced AI Detector Pattern Disruption**:
  * **Sub-Pixel Dimensional Shift**: Applies a `99.6%` micro-scale shift to break diffusion U-Net grid alignment (8x8 & 16x16 blocks).
  * **Micro-Noise Jitter**: Injects subtle pseudo-random RGB deltas ($\pm 2$ value shifts) across pixels to scramble artificial smoothness.
  * **DCT Frequency Re-quantization**: Re-encodes at `0.91` JPEG quality to scramble Discrete Cosine Transform feature maps analyzed by neural network detectors (Hive, Illuminarty).

## 🛠️ Technology Stack & Local Setup

* **Framework**: Next.js 16 (App Router + Turbopack)
* **Language**: TypeScript
* **Styling**: Vanilla CSS + TailwindCSS + Lucide Icons
* **Deployment**: Vercel + Cloudflare DNS

### Local Development Instructions

```bash
# 1. Clone repository
git clone git@github.com:inaamilyas/ai-text-cleaner.git
cd ai-text-cleaner

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build Verification

```bash

npm run build
```
